Set up in six commands.

Run them once from Discord with Manage Server. Then post the first op.

  1. /op-setup #ops @MembersWhere ops get posted and who gets pinged.
  2. /officer-role @OfficersThe role that runs officer commands without holding Manage Server.
  3. /verify-setup #verifyThe channel new members are greeted in.
  4. /ranks-setupCreate every rank role that is missing and start verified members on Private 1.
  5. /tickets-setupCreate the ticket channels and post the panel.
  6. /logs-setup #command-logWrite every notable action to this channel.
/op createPost the first op. The card goes up with its RSVP buttons.
